# Quick 30-Second Anti-Slop Scan

Use this for rapid review of any screen or page.

## Instant fails (stop immediately if present)

- [ ] Purple / indigo / violet gradient
- [ ] Gradient text
- [ ] Emoji icons
- [ ] Three identical feature cards
- [ ] Glassmorphism as decoration
- [ ] Soft colored glow
- [ ] “Unlock / Supercharge / Seamless” language

## High-probability tells

- [ ] Inter / Geist as the only typeface
- [ ] Eyebrow labels above headings
- [ ] Zero-padded numbers (01, 02, 03)
- [ ] Cards nested inside cards
- [ ] Side colored accent bars on cards
- [ ] Everything centered
- [ ] Fake round stats

## Craft check

- [ ] One clear primary action?
- [ ] Squint test: hierarchy still visible?
- [ ] Exactly one signature element?
- [ ] Real content only?

**Rule of thumb:**  
3+ instant fails → reject.  
1–2 instant fails → major surgery required.  
0 instant fails + weak hierarchy/signature → still not agency-grade.
